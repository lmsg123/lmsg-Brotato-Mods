# 危险的兔子：刷新概率增强

workshop：https://steamcommunity.com/sharedfiles/filedetails/?id=3818063211

v1.1.0：取消「危险的兔子」的数量上限，随本次实际支付的刷新费用升高增加其出现机会，附加补入概率最高 50%。不修改兔子的效果或价格，不需要 Mod Options。

## 安装

1. 将 `dist/lmsg-DangerousBunnyReroll.zip` 放到 Brotato 安装目录的 `mods/` 下（没有该目录则创建）。保持 ZIP 原样，不要解压。
2. 启用游戏的 ModLoader；如使用 Steam 启动选项，可加入 `--enable-mods`。
3. 重新启动游戏。日志中的 `Dangerous Bunny reroll enhancement loaded.` 表示入口脚本已加载。

项目中的 `lmsg-PerfectHookConfigurable` 是现有参考模组，未改动，也不是本模组的依赖。

创意工坊上传封面可选择 `mods-unpacked/lmsg-DangerousBunnyReroll/preview.jpg`（1254×1254，约 278 KB）。

## 概率规则

设本次实付刷新费用为 c，兔子当前波次、当前玩家价格修正后的购买价格为 P：

- c ≤ 20：完全使用原版结果，包括免费刷新。
- P > 20 且 20 < c < P：原版未出兔子时，以 `0.5 × ((c - 20) / (P - 20))²` 的机会补入。
- c > 20 且 c ≥ P：满足安全生成条件时，以 50% 的概率补入，费用更高也不会增加。
- P ≤ 20 时，20 的费用门槛优先；c > 20 时附加概率为 50%。

在原版允许补入、存在安全货位的情况下，最终出现概率为 `p0 + (1 - p0) × 0.5 × t²`，其中 `t = clamp((c - 20) / (P - 20), 0, 1)`（P > 20）。这里 p0 是取消兔子数量上限后原版整次刷新的出现概率，不是固定常数，也不是直接加 50 个百分点。

## 无限兔子

普通兔子和诅咒兔子共享的基础资源改为无限数量；原版自然生成和本模组补入都不会因已拥有 3 只而停止。兼容旧存档中仍带有有限数量字段的兔子副本，并保留其他物品的数量限制。该修改在模组运行时生效，不改写游戏安装资源或用户存档；卸载后原版上限重新生效，已购买的兔子不会被本模组删除。

## 原版规则优先

- 只作用于主动刷新，首次进入商店不增强。
- 费用在付款前捕获，补入在原版商店生成结束后、UI 更新前执行一次。
- 当前商店已有兔子时不补入，包括已锁定兔子。
- 上一批商店中剩余的未购买兔子会阻止本次补入，遵守原版排除规则。购买移除的兔子不再属于该列表。
- 除明确取消兔子的数量上限外，遵守解锁、可掉落、玩家/角色禁用、标签及物品组限制。
- 从安全的未锁定货位随机替换一个；允许替换多余武器，但不会降低适用的武器保底数量。
- 保护 `guaranteed_shop_items`、`forced_shop_items` 和不可正常掉落的特殊商品。
- 有增加/修改刷新品阶的特殊效果（例如金鱼）时，整次刷新保留原版结果，以免消耗特殊效果后用低品阶兔子覆盖它。
- 有 DebugService 强制商店物品时不补入。
- 没有安全货位时不补入；本版本不提供 100% 保底。
- 不删除原版特殊机制或其他 Mod 已生成的重复兔子。
- 多人按各玩家费用、价格和商店分别计算。

原版武器保底在本地源码中是 `current_wave ≤ 2` 时两把、`≤ 5` 时一把，并考虑锁定武器、角色最低数量及无武器槽位例外；不是固定保护两个物理货位。

验证说明：使用本地 Brotato 自带引擎运行隔离 GDScript 测试；尚未在完整游戏中验证实际商店及旧存档载入流程。测试详情见 `.scratch/dangerous-bunny/validation.md`。
