PerfectHookConfigurable
一个 Brotato 模组，让你控制鱼钩的诅咒行为和强度。
A Brotato mod that gives you control over the Fish Hook's curse behavior and strength.

Steam Workshop ID: 3804981251

功能 / Features
三种诅咒方式：每波至少一个 / 100% 诅咒所有锁定物品 / 原版概率
Three curse modes: At least one per wave / 100% all locked items / Vanilla chance

两种诅咒强度：原版动态强度 / 固定 110% 强度
Two curse strength options: Dynamic (Vanilla) / Fixed 110%

中英双语界面，根据游戏语言自动切换
Bilingual UI, auto-switches based on game language

与原版机制完全兼容，无鱼钩时模组完全隐身
Fully compatible with vanilla mechanics, completely invisible without a Fish Hook

安装 / Installation
前置模组 / Requires: Oudstand-ModOptions

通过 Steam 创意工坊订阅，或手动将 .zip 放入游戏根目录的 mods 文件夹
Subscribe on Steam Workshop, or manually place the .zip in the game's mods folder

兼容性 / Compatibility
游戏版本 / Game version: 1.1.15.x

ModLoader: 6.2.0+

多人游戏 / Multiplayer: 支持 / Supported
